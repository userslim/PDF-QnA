# Groq Setup

1. Go to [Groq Console](https://console.groq.com/) and sign up.
2. Generate an API key from the dashboard.
3. Add the key to your environment or `secrets.toml` as shown.
4. The app will use this key to call Groq's LLM.

The default models are:
- `mixtral-8x7b-32768` (recommended)
- `llama2-70b-4096`
